# Codex App SDK contributor instructions

Keep this repository focused on reusable Codex app-server runtime, Electron,
surface, and Vue concerns. Product-specific orchestration and non-Codex backend
abstractions belong in host applications.

Before adding, changing, reviewing, or deleting tests, read
`docs/guide/testing.md` and apply its value gate. A test is incomplete until
its claimed regression has a demonstrated red state.

Before handing off, committing, pushing, or calling repository work complete,
use the repo-local `definition-of-done` skill at
`.agents/skills/definition-of-done/SKILL.md`.
