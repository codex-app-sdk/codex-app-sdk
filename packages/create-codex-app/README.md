# create-codex-app

Scaffold a secure Electron and Vue application powered by Codex App SDK.

See the canonical
[scaffolding guide](https://nbonamy.github.io/codex-app-sdk/guide/scaffolding)
for publication status, npm and `npx` usage, repository-checkout usage, and all
command options.

The generated project includes the SDK backend and surface in Electron main,
typed preload APIs, a conversation sidebar, and the stock Vue conversation
pane. It refuses to overwrite non-empty directories.
